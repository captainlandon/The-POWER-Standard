# The POWER Standard website

Static public website for The POWER Standard, a civic accountability framework and platform stewarded by the Tao Institute for Actualization.

## Live site

[Open the published POWER website](https://power-standard-home.bandolando28.chatgpt.site)

## Preview locally

Open `index.html` in a browser. The site has no build dependencies.

## Files

- `index.html`: public homepage
- `platform.html`: product and public-tool architecture
- `methodology.html`: evidence and accountability safeguards
- `retrospective.html`: historical accountability module
- `parties.html`: American political parties civic primer
- `styles.css`: shared visual system
- `app.js`: accessible mobile navigation behavior
- `POWER_SITE_AUDIT.md`: source decisions and release audit

## Relationship to the platform prototype

This directory contains the explanatory public website. The repository's `src/` directory contains the interactive React platform prototype. Keeping these surfaces distinct allows the public narrative and the application architecture to evolve deliberately while sharing the same standard and project repository.

## Status

Working public-interest prototype. Demonstrations are illustrative and are not yet a live government record or legal determination.
