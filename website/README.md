# The POWER Standard website

Static public website for The POWER Standard, a civic accountability framework and platform stewarded by the Tao Institute for Actualization.

## Preview locally

Open `dist/index.html` in a browser. The site has no build dependencies.

## Files

- `dist/index.html`: public homepage
- `dist/platform.html`: product and public-tool architecture
- `dist/methodology.html`: evidence and accountability safeguards
- `dist/retrospective.html`: historical accountability module
- `dist/parties.html`: American political parties civic primer
- `dist/styles.css`: shared visual system
- `dist/app.js`: accessible mobile navigation behavior
- `POWER_SITE_AUDIT.md`: source decisions and release audit

## Status

Working public-interest prototype. Demonstrations are illustrative and are not yet a live government record or legal determination.
